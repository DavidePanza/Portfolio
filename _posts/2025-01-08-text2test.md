## Project Overview

Text2Test is a web app that generates exam-style questions and answers from user-uploaded PDF textbooks. It processes documents with PyMuPDF to extract text, detect tables of contents, and identify chapter boundaries. Users can either generate questions by selecting specific chapters or by entering topics of interest, making it possible to create targeted practice material. The app also provides PDF preview and inspection tools, with the generated questions available for download to support more efficient exam preparation.#

### Backend Architecture
- **LLM Integration**: Integrated Gemma2-12B-IT for intelligent question generation
- **Semantic Search**: Built semantic search using ChromaDB for content retrieval
- **Deployment**: LLM model deployed with Ollama and hosted on RunPod serverless platform

### Frontend
- **Interactive UI**: Streamlit app with user-friendly interface for file uploads and question generation

### Key Features
- PDF text extraction and processing
- Intelligent question generation based on content
- Downloadable Q&A format for exam preparation
- Semantic search for relevant content retrieval

### Technologies Used
- **Python**: Core development language
- **Streamlit**: Frontend framework
- **PyMuPDF**: PDF processing
- **ChromaDB**: Vector database for semantic search
- **SentenceTransformers**: Text embedding models
- **Ollama**: LLM deployment
- **RunPod**: Serverless hosting
- **Docker**: Containerization
- **RAG Architecture**: Retrieval-Augmented Generation
